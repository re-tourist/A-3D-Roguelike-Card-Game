# 项目文件结构与架构说明

## 开发思路与调度
- 全局常驻管理器：`GameManager`、`SceneFlowManager`、`UIManager`、`AudioManager` 作为单例常驻，通过 `DontDestroyOnLoad` 保持跨场景稳定。
- 启动流程：`BootManager` 在启动场景中确保创建 `GameManager` 与开发面板，随后设置游戏状态为 `MainMenu` 并加载主菜单场景。
- 场景调度：`SceneFlowManager.LoadScene(SceneType)` 采用 Additive 加载，设置激活场景后卸载上一场景，并通过 `EventBus.Publish("OnSceneLoaded", type)` 广播场景完成事件；同时确保 HUD 存在，禁用场景内临时 `EventSystem`，统一使用全局输入。
- 事件总线：`EventBus` 提供发布/订阅的松耦合通信，`HUDController`、`GameManager`、`UIManager` 等通过事件同步状态。
- UI 调度：`UIManager` 统一管理主 Canvas 的面板显示；`HUDController` 为全局叠加层，控制顶栏显示、计时与右下角“前进”按钮；ESC 菜单通过 `ESCMenuController/Animator/Input` 组合实现。
- 地图与存档：
  - 旧图系统：`MapController` + `MapGenerator` + `MapGraph/MapNode`。点击节点后标记访问并用 `UpdateAvailability` 仅开放当前节点出边指向的下一层节点；通过 `SaveManager.SaveMapProgress` 持久化，返回地图由 `TryLoadMapProgress` 恢复并更新可走节点。
  - 新图系统：`LayerMapGenerator` + `LayerMapGraph` + `MapRenderer`。点击节点后以当前节点 id 计算 `reachable`，通过 `SaveLayerMapProgress/TryLoadLayerMapProgress` 持久化与恢复。
- 输入系统：统一常驻 `EventSystem`；为防止 UI 点击链路在少数场景失效，HUD 前进按钮除了 `Button.onClick` 外，增加 `GraphicRaycaster` 射线回退命中触发，提升稳健性。

## 文件作用速览
- `Assets/Scripts/Core/GameManager.cs`：游戏生命周期与全局状态管理，初始化核心系统并切换到主菜单。
- `Assets/Scripts/Core/SceneFlowManager.cs`：Additive 场景加载与卸载、设置激活场景、广播 `OnSceneLoaded`，确保 HUD 常驻与输入统一。
- `Assets/Scripts/Core/EventBus.cs`：轻量事件总线，模块间发布/订阅，解耦 UI 与场景逻辑。
- `Assets/Scripts/Core/BootManager.cs`：启动场景入口，创建 `GameManager` 与开发面板，准备运行环境。
- `Assets/Scripts/Core/DevControlPanel.cs`：开发开关（如存档开关），便于调试与快速切换；默认启用存档。
- `Assets/Scripts/Core/DevFlags.cs`：全局开发标志位（`DisableSaves`）。
- `Assets/Scripts/Core/SaveManager.cs`：旧图与新图的进度保存/加载（当前节点、节点状态、图结构），返回地图后用于恢复可走节点。
- `Assets/Scripts/Audio/AudioManager.cs`：音频系统入口，统一管理背景音乐与音效（占位/简化实现）。
- `Assets/Scripts/UI/UIManager.cs`：全局 UI 管理器，负责主 Canvas 面板的显示与切换，以及 ESC 菜单接入。
- `Assets/Scripts/UI/HUD/HUDController.cs`：全局叠加层，显示顶栏、计时与右下角“前进”按钮；含输入稳健性增强与场景事件响应。
- `Assets/Scripts/UI/ESCMenu/ESCMenuController.cs`：ESC 菜单的开关与交互逻辑。
- `Assets/Scripts/UI/ESCMenu/ESCMenuAnimator.cs`：ESC 菜单动画与视觉层控制。
- `Assets/Scripts/UI/ESCMenu/ESCMenuInput.cs`：监听 `Escape` 键并触发 ESC 菜单切换。
- `Assets/Scripts/UI/MainMenu/MainMenuController.cs`：主菜单按钮接线、存档感知、继续/新游戏/放弃/设置/退出等交互。
- `Assets/Scripts/Map/MapController.cs`：旧图系统的生成与交互，点击节点后开放出边指向的下一层节点并保存进度。
- `Assets/Scripts/Map/MapGenerator.cs`：旧图系统的节点与连接生成，以及 `UpdateAvailability` 规则。
- `Assets/Scripts/Map/MapGraph.cs`：旧图与新图所需的数据结构集合（`MapGraph`、`LayerMapGraph`）。
- `Assets/Scripts/Map/MapNode.cs`：旧图节点数据结构（层、行、类型、状态、出边）。
- `Assets/Scripts/Map/MapEnums.cs`：旧图的节点类型与状态枚举。
- `Assets/Scripts/Map/MapTypes.cs`：新图的节点类型枚举（分层图）。
- `Assets/Scripts/Map/LayerMapGenerator.cs`：分层图生成器，提供非交叉连线、Boss 收束与间距规则。
- `Assets/Scripts/Map/MapRenderer.cs`：分层图渲染与互动，负责布局、连线绘制、可走节点刷新与进度保存/恢复。
- `Assets/Scenes/*.unity`：主菜单、地图与各节点场景（战斗/事件/休息/商店/奖励/启动），由 `SceneFlowManager` 调度加载与卸载。
